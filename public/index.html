กำหนดเวอร์ชันล่าสุด บังคับให้อัปเดต และใส่ลิงก์ดาวน์โหลดตัวติดตั้งใหม่

เครื่องที่กำลังเปิดใช้งาน (Live Active Clients)

ตรวจสอบเครื่อง Desktop ที่กำลังรันโปรแกรมและส่ง Heartbeat เข้ามา

สถานะ ผู้ใช้งาน (User) เว็บไซต์ (Site) เวอร์ชัน รหัสเครื่อง (Device UUID) ชื่อเครื่อง / OS เปิดใช้งาน (Uptime) ออนไลน์ล่าสุด IP Address
