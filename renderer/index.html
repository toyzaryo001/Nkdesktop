NEW UI
1. คอลัมน์ซ้าย : แบบฟอร์ม
  • ค้นหาแบบฟอร์ม: พิมพ์กรองชื่อฟอร์มได้ทันที
  • ปุ่ม + สร้าง: สร้างเทมเพลตฟอร์มใหม่แชร์ไปทุกเครื่อง
  • ปุ่ม 🔄 รีเฟรช: ซิงค์ดึงแบบฟอร์มล่าสุดจากคลาวด์
  • ป้ายสถานะ: ตรวจสอบการเชื่อมต่อออนไลน์
2. คอลัมน์กลาง : ช่องกรอกตัวแปร
  • ตารางรายการหลายหมวด: มีปุ่มเพิ่มแถว & วางยอดออโต้
  • ปุ่ม 🗑️ ล้างค่าที่กรอก: เคลียร์ค่าทั้งหมดเพื่อเริ่มรอบใหม่
  • ปุ่มลัดเลือกเดือน: มีปุ่ม [เดือนนี้] และ [เดือนก่อน]
  • Auto-Save: บันทึกลงเครื่องสดทุกตัวอักษร ข้อมูลไม่หาย
3. คอลัมน์ขวา : Card ตัวอย่างสด
  • Live Preview: เห็นผลลัพธ์ทันทีขณะพิมพ์เต็มหน้าจอ
  • ตัด ** สำหรับ LINE: ส่งในแชท LINE ได้อย่างสะอาดตา
  • ตัวนับอักษร/บรรทัด: ทราบความยาวข้อความทันที

เหมาะกับฟอร์มสรุปยอดส่งเงิน

กรณีฟอร์มมีหลายส่วน เช่น True Wallet, บัญชีบุคคล, Payment Gateway หรือ เติม Manual สามารถสร้างตารางแยกหมวดอิสระได้ทันที โดยใส่ชื่อหมวดหลังเครื่องหมาย : ในเทมเพลต:

หมวดหมู่ที่ต้องการ แท็กตารางรายการใน Template แท็กรวมเฉพาะหมวด (Subtotal) ผลลัพธ์ที่ได้
หมวดทั่วไป <รายการ> <รวมยอด> หรือ <รวม> เปิด 1 ตารางรายการทั่วไป
หมวด True Wallet <รายการ:วอเลท> <รวม:วอเลท> เปิดตารางเฉพาะวอเลท + รวมยอดเฉพาะวอเลท
หมวดบัญชีบุคคล <รายการ:บุคคล> <รวม:บุคคล> เปิดตารางบัญชีบุคคล + รวมยอดเฉพาะบุคคล
หมวด Gateway / อื่นๆ <รายการ:เกตเวย์> <รวม:เกตเวย์> เปิดตารางเกตเวย์ + รวมยอดเฉพาะเกตเวย์
⭐ รวมยอดทุกหมวด - <รวมทั้งหมด> รวมยอดเงินของทุกหมวดเข้าด้วยกัน (Grand Total)

ปุ่มลัด "⚡ วางหลายยอดออโต้": แต่ละหมวดจะมีปุ่มนี้อยู่ สามารถ Copy ยอดเงินหลายบรรทัดจากแชตมาวาง เช่น 1,500\n320.22\n500 ระบบจะแยกแถวและคำนวณยอดเงินให้ทันทีโดยไม่ต้องพิมพ์ทีละแถว!

สูตรคำนวณคณิตศาสตร์อัตโนมัติ (Formula Engine)

ไม่ต้องใช้เครื่องคิดเลข

ใส่แท็ก <คำนวณ: สูตรคณิตศาสตร์> ใน Template โดยนำชื่อตัวแปรหรือยอดรวมมาใส่ในสูตรได้เลย รองรับบวก +, ลบ -, คูณ *, หาร /, วงเล็บ ( ) และเปอร์เซ็นต์ %:

1. คำนวณค่าธรรมเนียม 2.9%
<คำนวณ: [ยอดเงิน] * 2.9 / 100>
💡 ถ้าช่อง [ยอดเงิน] กรอก 3,000 ระบบจะคำนวณเป็น 87.00 ให้ทันที
2. คำนวณยอดสุทธิ (ยอดเงิน - ค่าธรรมเนียม)
<คำนวณ: [ยอดเงิน] - ([ยอดเงิน] * 2.9 / 100)>
💡 ถ้าช่อง [ยอดเงิน] คือ 3,000 จะได้ยอดสุทธิ 2,913.00 อัตโนมัติ
3. คำนวณผลต่างระหว่างหมวด
<คำนวณ: [รวม:วอเลท] - [รวม:บุคคล]>
💡 นำผลรวมของหมวดวอเลท มาลบกับผลรวมของหมวดบุคคลได้ทันที
4. ใส่เครื่องหมาย % ได้โดยตรง
<คำนวณ: [ยอดเงิน] * 2.9%>
💡 พิมพ์ 2.9% ได้ทันที ระบบจะแปลงเป็นหาร 100 ให้อัตโนมัติ
